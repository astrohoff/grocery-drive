# List file format

Each list is one `.md` file in the Groceries folder. The filename is the list name.

The body is only lines of `- [ ] item` or `- [x] item`.

Do not add headings, categories, quantities as separate fields, ids, or HTML comments.

To add an item, append an unchecked line. To check it, change the line to `- [x]`. To remove it, delete the line.

The app groups lines into aisles on screen. The file has no aisle information.
